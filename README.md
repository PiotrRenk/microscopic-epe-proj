# Extraprostatic extension prediction using machine learning

Currently this repository focuses on deriving a ML model to predict lymph node involvement (N+) and ISUP grade upgrading between biopsy and radical prostatectomy (RP) for patients with prostate cancer.

# Setup:
1. Clone the repository
2. Install the required dependencies using `uv`:
    ```bash
    uv sync
    ```
# Folder structure:
- `notebooks/`: main folder containing Jupyter notebooks with data processing and model fitting
- `src/`: helper functions used in the notebooks
- `models/`: saved ML models
- `archive/`: old notebooks and scripts
